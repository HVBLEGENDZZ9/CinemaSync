CinemaSync is a personal, premium-feeling synchronized video watching tool for two people in a long-distance relationship.

**Why:** The user wants an intimate, intentional tool — not a generic watch party app. Every design choice should feel deliberate and minimal.

**How to apply:** Keep the UI dark, minimal, and polished. No unnecessary features. The sync logic is the critical path — prioritize correctness over flashiness. Design system uses specific fonts (Figtree + DM Mono), specific color palette, and restrained motion.
